🏭 小型生产型企业 ERP 系统 MVP

  • 智能预警提醒
  • 扫码入库出库
  • 库存状态可视化
🏭
生产管理
  • 生产订单管理
  • 生产排班看板
  • 工时统计分析
  • 质量控制流程
📋
订单管理
  • 销售订单跟踪
  • 采购订单管理
  • 客户信息维护
  • 订单状态监控
🤖
AI智能助手
  • 中文自然语言交互
  • 业务数据智能查询
  • 快捷操作指导
  • 预设问答系统

🎯 MVP 目标

  • 快速部署：2-3周完成开发，1周内可演示
  • 功能完整：覆盖核心业务流程，支持端到端演示
  • 用户友好：中文界面，直观操作，降低学习成本
  • 可扩展性：模块化设计，便于后续功能扩展

📱 快速开始

  1. 安装模块：manufacturing_mvp
  2. 访问主菜单：🏭 智能制造MVP
  3. 体验AI助手：点击 🤖 AI助手
  4. 扫码操作：在库存管理中使用扫码功能
  5. 查看生产看板：实时监控生产状态

🔧 系统要求

  • Odoo 18.0+
  • Python 3.8+
  • PostgreSQL 12+
  • 现代浏览器（Chrome, Firefox, Safari）
💡 演示提示：
系统已预置演示数据，包括产品、库存、生产订单等，可直接体验完整业务流程。 建议从AI助手开始，了解系统功能和使用方法。
